# «Прокачай тусовку» — вертикальный прототип

Небольшой автономный браузерный 2D-прототип с видом сверху для дальнейшей публикации в Яндекс Играх. В нём нет чужих моделей, текстур и музыки: вся локация нарисована кодом на Canvas.

## Запуск

Нужен Node.js 20+ и пакетный менеджер pnpm.

```bash
pnpm install
pnpm dev
```

Откройте адрес, который покажет Vite (обычно `http://localhost:5173`). Для итоговой проверки сборки: `pnpm build`, затем `pnpm preview`.

## Управление

- ПК: `WASD` — движение, `E` — взаимодействие.
- Телефон: виртуальный стик — движение, розовая кнопка — взаимодействие.

Подойдите к жёлтому автомату или NPC, чтобы получить первые монеты. Покупка улучшения меняет сцену и увеличивает пассивный доход.

## Структура

- `src/core/` — игровой цикл и ввод.
- `src/player/` — персонаж и камера третьего лица.
- `src/world/` — сцена, NPC, интерактивные объекты и визуальные улучшения.
- `src/economy/` — баланс и списание/начисление монет.
- `src/ui/` — HUD, магазин и подсказки.
- `src/content/trends.js` — независимое описание текущего тренда; отсюда удобно добавлять будущие сезонные правила и награды.

## Что уже работает

2D-площадка, ПК/мобильное управление, три NPC, взаимодействия, валюта, пассивный доход и четыре расширения территории: музыка, лаунж, фуд-трак и сцена.
